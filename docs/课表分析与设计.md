# 课表.xls 特征分析与课程表 App 设计说明

> 分析对象：`课表.xls`（2026-2027 学年第 1 学期，学生「王梓俊」，财政金融学院·金融学(本科)·2025 级）

---

## 一、文件本身特征（已逐格解析验证）

* 真实 **OLE2 / BIFF8** 二进制格式（非 HTML 伪装），单工作表，表名 `skb`。
* 布局（坐标从 0 起，已按单元格坐标导出验证）：

| 区域 | 内容 |
|---|---|
| 第 1 行 | 标题：`2026-2027学年第1学期 王梓俊 课表`（合并 A:C） |
| 第 2 行 | 学生信息：`年级：2025 院系：财政金融学院 专业：金融学(本科) 姓名：王梓俊`（合并 B:H） |
| 第 3 行 | 表头：`节次` + `星期一`…`星期日`（7 天均为列） |
| 第 4–15 行 | 节次序号 1–12（每行一节，即一个「小节」） |
| 第 16–17 行 | `备注` 行（内容为空） |

* 每个课程序格内为**多行文本块**：课程名、教师行（含 `【周次】`，如 `薛俊生【1-9,11-16,18周】`）、教室行；同一格可叠放多个课（以空行分隔），例如星期一第 5 节同时出现「劳动技能」与「大学生心理健康教育」。
* 课程跨「小节」时，源文件把相同文本**逐行重复写入每个小节格**（例如周二 1-2 节的毛概写在第 4、5 两行）。这就是需要「避免无意义重复」的根源——显示时应把竖向连续同文本合并为一个课程块。

### 时间规则（用户注释，12 小时制）
节次按**每两节为一节课**（一个大节）排布，节次序号保留：

| 大节 | 小节 | 时间 |
|---|---|---|
| 1-2 节 | 第1、2节 | 8:20 – 10:00 |
| 3-4 节 | 第3、4节 | 10:20 – 12:00 |
| 5-6 节 | 第5、6节 | 13:20 – 15:00（文件写 1:20–3:00） |
| 7-8 节 | 第7、8节 | 15:20 – 17:00（文件写 3:20–5:00） |
| 9-10 节 | 第9、10节 | 18:00 – 19:30（文件写 6:00–7:30） |

> 第 11、12 节源表未排课、也无时间定义。

### 周次写法
教师行 `【…】` 内的写法与语义：
`1-9,11-16,18周`（连续含两端、跳过第 10 周）、`2-8(双),12-16(双)周`（偶数周）、`1-15(单)周`（奇数周）、`4,9,13周`（零星周）、`17周`（单周）。全表最大周次为 18 ⇒ **学期共 18 周**；多数课程跳过第 10 周（推测为考试/活动周）。

特征结论：
1. 每周一课程分布正确、周次过滤不冲突（单/双周交替由周次解析自动完成）。
2. 无课程占用 11-12 节与周六日；周六日表头存在但为空 ⇒ 界面默认展示周一–周五，设置中可显示周末。
3. 「无意义重复」共两类：① 同一课程文本在相邻小节逐格重复（竖向合并）；② 第17周劳动课在周一到周五每格重复（按天折叠为单块，只在该周显示）。

## 三、App 需求 → 设计映射

| 需求 | 设计 |
|---|---|
| UI 类似市面课程表 | 主色卡片式周课表（网格 + 色块）、底部「周 / 日 / 月」切换 + 课程总览、设置、导入；Material 3 |
| 18 周日程按日期排布 | 学期第 1 周周一默认为 **2026-08-31**（设置内可改）；任意日期 → `((日期-起点)/7)+1` 得周次；超出 1–18 周则显示「假期/非本学期」 |
| 月/周/日三层状态 | 月（学期内逐月日历，格内课程圆点计数，点击进入日）、周（7 天网格+周次日期条）、日（当天课程列表卡片） |
| 每天发送当天课程通知 | 每日早晨固定时间（默认 07:30）汇总当天课程通知：AlarmManager 每日重复 + 开机重排 + Android 13+ 通知权限 |
| xls 内容详尽呈现 | 原始多行块文本保留在 `raw` 字段；周视图点卡片、日视图、课程总览均可看教师/周次/教室原文 |
| 避免无意义重复 | 竖向连续同文本自动合并为块；课程总览按「课程名+教师」聚合唯一展示 |
| 导入同类型不同内容 | 内置 2 个解析器：BIFF8(.xls 原生)、OOXML(.xlsx)；自动识别 竖排/横排 两种表头方向、节次 1..N、周次写法、单/双周；App 不内置任何示例 |

## 四、通用导入的识别规则（对同族文件健壮）
1. 读工作簿 → 每个工作表 → 文本网格 `(行,列)->文本` + 合并区域。
2. 找表头行：某格为「节次/节/时间」且右侧/下方存在 星期 标签；支持 星期X/周X/周 与 周一..周日 横排或竖排。
3. 节次序列 1..N（升序连续）；每一节次行/列对应一个小节；第 2 小节与第 2k-1 小节合并为一个「课块」用于时间标注。
4. 每个课程序格文本按空行分块 → 每块首行为课程名，含 `【…周】` 的行拆出教师名与周次表达式，其余行取末行作教室；无周次注解 ⇒ 视为 1..N 周全覆盖（仍保留原文）。
5. 竖向连续同签名块合并为一条排课记录（保留 startSlot + slotSpan）。
6. 顶部信息行（含「学期/课表」与 年级/院系/专业/姓名/班级/学号）整行保留并解析键值，作为页眉展示 —— **个人信息完全来自导入文件，App 不内置**。

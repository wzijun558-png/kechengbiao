# 课表分析 → 课程表 App（交付说明）

根据你提供的 `课表.xls`（2026-2027 学年第 1 学期 · 王梓俊，18 周，节次 1-12、每两节为一课，12 小时制时间注释）进行分析并产出的完整交付物。

## 交付物一览

| 路径 | 说明 |
|---|---|
| `docs/课表分析与设计.md` | 文件特征逐格分析、时间/周次规则、10 门课 21 条排课清单、需求→设计映射 |
| `CourseTableApp/` | **Android 源码工程**（Kotlin + Material 3）；本机联网编译产物见 `CourseTableApp/app/build/outputs/apk/debug/app-debug.apk` |
| `demo-web/` | 在线 Web 演示（同款 UI：月/周/日/总览 + 每日通知模拟；仅预览参考，APK 不含任何示例数据） |
| `samples/` | 分析/测试用数据：`课表.xls`（原文）、内容等价的 `.xlsx`（不进入 APK） |
| `tools/` | 解析与分析脚本：`read_xls.py`（BIFF8 解析）、`extract_canonical.py`（规范数据提取/校验/xlsx 副本）、`netfetch.py`（代理下载）等 |

## 关键决策（来自你的确认）
1. 本轮交付 **真实 debug APK 安装包**（本机联网下载 JDK17 + Android SDK + Gradle 编译）。
2. 学期第 1 周周一 = **2026-08-31**（可在 App 设置内修改）。
3. 通知：**锁屏可见**；用户可任选「**时钟（本机闹钟）**」或「**手机日历（同步系统日历）**」作为提醒方式（默认 07:30 / 课前 10 分钟，App 内可调）。
4. 联网自检测更新：启动时每日一次 + 设置内「检查更新」；更新清单为远端 JSON。**当前版本 1.0（versionCode 1）**。
5. **不内置任何示例数据/演示**：App 打开为空，仅支持导入 **.xls / .xlsx**；姓名/班级/院系等随导入文件内容展示。
6. demo-web 保留为 UI 预览参考（其中 JSON 导入仅为浏览器预览便利，正式 App 不受支持）。

## 界面优化（本轮）
- 周课表**已取消左侧“节次·时间”显示**：仅保留“星期/日期表头 + 天列网格 + 课程块”，课程块仍按小节纵向排布、起点对齐。
- 一门课**一种固定颜色**：按课程名排序后以黄金角(137.508°)推进色相，数量再多也互不撞色、肉眼易区分；周/日/月/总览全局一致。
- 布局简化并加彩：标题胶囊、今日列/选中日高亮、浅色同色相卡片底 + 实色侧条。

## 课表内容要点（已逐格验证）
- 解析出 **10 门课、21 条排课**：劳动技能(仅17周)、毛概(理论)、线性代数B2(理论)、经济法概论(理论)、证券投资学(理论)、大学生心理健康教育(理论)、体育3(理论)、国际金融(理论)、宏观经济学(理论)、创业基础(理论)。

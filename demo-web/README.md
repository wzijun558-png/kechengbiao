# 课程表 Web 演示（同款 UI 预览）

与 `CourseTableApp`（Android）使用**同一份课表数据与同一套逻辑**（周次表达式、单双周、竖向重复合并、10 小节时间轨）实现的浏览器演示，用于快速预览 UI 与交互，不依赖任何服务器。

## 运行方式（任选其一）

**直接双击** `index.html`（数据内嵌于 `data.js`，离线可用）；
或本地起 http 服务（某些浏览器限制 file:// 读取）：
```bash
cd demo-web
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 提供的能力
- 底部切换：**周课表 / 日程(日) / 月视图 / 全部课程**（课程按“名称+教师”聚合去重、逐次列出）。
- 顶部 ‹ › 切换周 / 日 / 月；☰ 菜单含：全部课程、导入(预览用)、每日通知、时间说明。
- 周视图：10 小节（第1节…第10节） × 周一~周五网格（周六日无课时自动隐藏），左侧为**大节合并时间轨**（如“第1-2节 8:20-10:00”跨两行居中，与两小节课程块同高同起点）；课程色块按占用小节跨行；第 17 周的劳动课自动折叠成整块。
- 配色：**一门课一种颜色**（黄金角渐进色相、与 Android 端一致），周/日/月/总览全局同一颜色，肉眼易区分。
- 月视图：学期内逐月日历，格内彩色圆点 = 当天课程，W# = 第几周，点击进入当日。
- 每日课程通知（演示）：开关 + 时间（默认 07:30），到点或点「立即发送」展示当天课程汇总（支持浏览器 Notification，未授权时页面内横幅）。
- 导入（浏览器预览用）：可导入同结构 `.json` 试效果；**正式 Android App 仅支持 `.xls/.xlsx` 且不内置示例**（`samples/` 附示例文件供 App 端试验）。
